# 手柄控制

这是实验室场景的可选 macOS Xbox 手柄控制器。它通过 macOS 原生 GameController 读取输入，不需要额外的硬件驱动。

从仓库根目录启动：

```sh
./手柄控制.command
```

或者激活安装依赖的环境后执行 `python launch.py --gamepad`。

点击 MuJoCo 窗口，松开 RT 并回中摇杆，再按住 RT 操作。

| 控件 | 作用 |
|---|---|
| A / B | 选择左臂 / 右臂 |
| RT | 启用运动；松开停止新目标增量 |
| LT | 精细慢速 |
| 左摇杆 | 末端前后、左右移动 |
| 右摇杆上下 | 末端升高、降低 |
| 右摇杆左右 | 末端偏航旋转 |
| 十字键 | 调整末端俯仰、滚转 |
| LB / RB | 打开、关闭当前夹爪 |
| Menu | 暂停、恢复操控 |
| 键盘 Space / Esc | 停止操控 / 退出 |

实验室配置的底盘和升降保持固定。窗口失去焦点、手柄断连或输入超时会停止运动指令；重连后先回中摇杆并释放 RT。

手柄模块依赖 `pyobjc-core` 和 `pyobjc-framework-Cocoa`，只在 macOS 上启用。没有手柄时可以直接运行 `launch_scene.command`。
